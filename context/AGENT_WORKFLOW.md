# Agent Workflow

## Stage 1: Build dataset
Generate trajectories for each demo family.

## Stage 2: Extract representations
Transform each trajectory into multiple representation spaces.

## Stage 3: Compute metrics
Evaluate smoothness, curvature, rank, and interpolation error.

## Stage 4: Plot and summarize
Generate figures and markdown summary.

## Stage 5: Recommend next step
Suggest which representation should be used for later generative modeling.
