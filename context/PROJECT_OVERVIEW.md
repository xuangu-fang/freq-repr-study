# Project Overview

## Goal
Study which representation space makes the frequency trajectory of PDE solution families smoother, lower-dimensional, and easier to interpolate/extrapolate.

## Unit of Analysis
One sample is one frequency trajectory:
{u_w1, u_w2, ..., u_wM}

## Current Scope
- 2D fields only
- No geometry
- No full generative modeling yet
- Focus on representation study

## Demo Families
1. phase_family
2. screened_poisson

- datasets
